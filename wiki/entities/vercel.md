# Vercel

*Frontend cloud hosting/deployment platform.*

## Background

Commercial hosting platform commonly used for deploying static and server-rendered web frontends, with a workflow optimized for fast, git-connected deploys.

## Role in This Wiki

The publishing step in [[concepts/directory-website-seo-play|Cody Schneider's directory website tactic]] — after Claude Code one-shot builds the site, it's published to Vercel, then indexed via [[entities/google-search-console|Google Search Console]].
