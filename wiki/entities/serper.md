# Serper

*SERP (search engine results page) scraping API.*

## Background

An API that returns structured Google search results programmatically, used for automated SERP research rather than manual search-and-read.

## Role in This Wiki

The competitive-research step in [[concepts/founder-perspective-content-moat|Cody Schneider's SEO for SaaS 101 pipeline]] — for each target bottom-of-funnel keyword, Serper scrapes what's currently ranking on page 1, which is then combined with a recorded founder perspective to write the article.

## Key Contributions / Actions

- Scrapes page-1 SERP results per target keyword, per [[sources/codyschneider-seo-for-saas-101]].
