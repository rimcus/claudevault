# Google Search Console

*Google's free tool for monitoring how a site is indexed and how it performs in Google Search.*

## Background

Standard SEO/webmaster tool providing indexing status, search query performance, and crawl data for a site.

## Role in This Wiki

Used in two steps of [[concepts/directory-website-seo-play|the directory website tactic]]: to submit the site for indexing after publishing, and as the data source for the monthly content-gap analysis that drives the site's refresh cycle. Also part of the three-tool conversion-tracking stack (with [[entities/google-tag-manager|Google Tag Manager]] and [[entities/google-analytics-4|Google Analytics 4]]) in [[concepts/founder-perspective-content-moat|the SEO for SaaS 101 pipeline]].

## Key Contributions / Actions

- Indexing gate for the newly built directory site.
- Query/performance data source for monthly content-gap analysis, per [[sources/codyschneider-ai-media-company-playbook]].
- Conversion-event tracking alongside GTM and GA4, per [[sources/codyschneider-seo-for-saas-101]].
