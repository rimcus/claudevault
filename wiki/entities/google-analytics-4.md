# Google Analytics 4

*Google's web analytics platform.*

## Background

Standard event-based web analytics tool; tracks user behavior and conversion events across a site.

## Role in This Wiki

Part of the three-tool conversion-tracking stack in [[concepts/founder-perspective-content-moat|Cody Schneider's SEO for SaaS 101 pipeline]], alongside Google Tag Manager and [[entities/google-search-console|Google Search Console]] — tracks the conversion event against the specific landing page that produced it.

## Key Contributions / Actions
