# Growth Loop

A self-reinforcing cycle in which the outputs of a growth activity become the inputs for the next iteration — making each cycle better than the last. The opposite of a one-time campaign. Appears in [[Cody Schneider]]'s [[AI UGC Ads]] pipeline as the explicit design principle.

## The Loop in the UGC Ads Context

```
Run 100+ ads
    → Measure CLV winners (via Graphed + Stripe)
    → Remix winners
    → Run new batch with winning patterns
    → Repeat
```

Each loop cycle narrows in on what actually converts customers, not just what gets clicks. Over time the creative quality compounds.

## Why This Matters

A growth loop is the [[Knowledge Compounding]] principle applied to paid growth. Just as a wiki gets richer with each ingest, a growth loop gets more effective with each cycle — because it learns from real revenue data, not guesses.

Without a loop, each ad campaign starts from scratch. With a loop, each campaign starts from the accumulated learning of all previous campaigns.

## Connections

The same structure applies to:
- **SEO content pipeline:** which posts drive signups → build more in that category
- **Cold email:** which sequences get replies → remix those subject lines and openers
- **Product:** which features drive retention → double down on those
