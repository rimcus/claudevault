# The Complete SaaS Blueprint (Folder Tree)

**Author:** [[Hridoy Rehman]]
**Date:** 2026-03-10
**Source:** X/Twitter thread

## Core Thesis

A SaaS business has 16 distinct phases, each with 5–6 discrete sub-disciplines. Visualized as a directory tree, this makes the full scope of what "building a SaaS" actually requires impossible to ignore. Most founders skip phases or treat them as optional — this blueprint makes the skeleton explicit.

## Key Points

- The blueprint covers **16 phases** from raw idea to exit strategy
- Each phase has **5–6 sub-disciplines** — the tree has ~85 leaf nodes total
- The structure is sequential but phases overlap in practice (e.g. Analytics runs from Launch onwards, not just its own phase)
- Community response: overwhelmingly used as a checklist; Botanium noted each folder maps directly to an AI agent ("assign each part to an agent and start cooking")
- Distribution was notably missing from the original and added after community pushback — reflects a common founder blind spot

## The 16 Phases

| Phase | Key Sub-Disciplines |
|-------|-------------------|
| **Idea** | Problem Discovery, Market Research, Niche Selection, Competitor Analysis, Opportunity Mapping |
| **Validation** | Customer Interviews, Landing Page Test, Waitlist, Pre-Sales, Demand Testing |
| **Planning** | Product Roadmap, Feature Prioritization, MVP Scope, Tech Stack, Development Plan |
| **Design** | Wireframes, UI Design, UX Flows, Prototype, Design System |
| **Development** | Frontend, Backend, APIs, Database, Authentication, Integrations |
| **Infrastructure** | Cloud Hosting, DevOps, CI/CD, Monitoring, Security |
| **Testing** | Unit Testing, Integration Testing, Bug Fixing, Performance Testing, Beta Testing |
| **Launch** | Landing Page, Product Hunt, Beta Users, Early Adopters, Public Release |
| **Acquisition** | SEO Wins, Content Marketing, Social Media, Cold Email, Influencer Outreach, Affiliate Marketing |
| **Distribution** | Directories, SaaS Marketplaces, Communities, Partnerships, Integrations |
| **Conversion** | Sales Funnel, Free Trial, Freemium Model, Pricing Strategy, Checkout Optimization |
| **Revenue** | Subscriptions, Upsells, Add-ons, Annual Plans, Enterprise Deals |
| **Analytics** | User Tracking, Funnel Analysis, Cohort Analysis, KPI Dashboard, A/B Testing |
| **Retention** | User Onboarding, Email Automation, Customer Support, Feature Adoption, Churn Reduction |
| **Growth** | Referral Programs, Community Building, Product-Led Growth, Viral Loops, Expansion Strategy |
| **Scaling** | Automation, Hiring, Systems, Global Expansion, Exit Strategy |

## My Notes

The most immediately useful framing of this blueprint: **use it as an audit**. For any SaaS at any stage, walk down the tree and identify which folders are empty. Those are the gaps.

The @botanium observation is significant: this blueprint maps cleanly onto the [[GTM Agents]] concept from [[sources/codyschneider-gtm-agents]]. Schneider's thread implements agents for the Acquisition phase (SEO, cold email, ads) and the Retention phase (email nurture). Together they suggest a near-complete agentic coverage of the post-launch SaaS stack.

The Distribution phase being absent from the original and only added after community feedback is a meaningful data point — distribution is the most commonly underweighted phase by technical founders.
